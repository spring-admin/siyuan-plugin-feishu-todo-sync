# 飞书待办同步

在思源「任务笔记管理」插件的待办任务与飞书「任务 (Task)」待办之间进行双向同步。

## 功能

- **定时同步**：默认每 60 秒轮询一次，并监听任务数据变化尽量即时同步；顶栏提供「立即同步」按钮。
- **思源 → 飞书**：把设置中勾选的多个分类下的待办创建/更新到飞书任务清单（标题、备注、截止时间、完成状态）。
- **飞书 → 思源**：把飞书任务清单中的任务新建到思源「飞书待办」分类。
- **冲突处理**：同一条任务两边都修改时，按「最后修改时间优先」覆盖。
- **仅桌面端**：只在思源桌面客户端运行时生效。

## 使用前提

需要「任务笔记管理」插件（`siyuan-plugin-task-note-management`）已安装并启用，且存在「飞书待办」分类（默认已内置 `category_feishu_todo`）。

## 飞书侧配置（一次性）

1. 登录[飞书开放平台](https://open.feishu.cn/)，创建「企业自建应用」，记录 **App ID** 与 **App Secret**。
2. 在「权限管理」中开通并申请任务相关权限，至少包含：
   - `task:task:read`（查看任务）
   - `task:task:write`（创建/更新任务；或 `task:task:writeonly`）
   - `offline_access`（获取 refresh_token）
3. 在「安全设置 > 重定向 URL」中添加：`http://127.0.0.1:18080/callback`（与插件设置中的 OAuth 回调端口保持一致）。
4. 发布应用版本使权限生效。
5. 回到本插件设置，填入 App ID / App Secret，点击「授权飞书」，在浏览器完成授权。

## 设置项

- **飞书 App ID / App Secret**：飞书应用凭证。
- **授权权限 scope**：默认 `task:task:read task:task:write offline_access`。
- **OAuth 回调端口**：默认 `18080`，需与飞书应用重定向 URL 一致。
- **飞书任务清单**：思源任务同步到的目标清单（飞书默认「待办」）；点击「刷新清单」后选择。
- **同步间隔**：默认 60 秒，最小 10 秒。
- **同步到飞书的分类**：多选，勾选后该分类下的待办同步到飞书。

## 已知范围（v0.1）

- 仅同步非重复任务；重复任务暂不双向传播。
- 任务删除暂不双向传播（一侧删除不会删除另一侧）。
- 优先级暂不映射到飞书（飞书任务基础字段无直接优先级）。

## 数据说明

- 读取任务插件存储：`data/storage/petal/siyuan-plugin-task-note-management/reminder.json`、`categories.json`。
- 飞书 → 思源时写回 `reminder.json`（新增任务，分类为「飞书待办」），任务插件会自动刷新。
- 本插件自身数据（token、映射表、设置）保存在插件自身存储目录。
