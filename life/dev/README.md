# 飞书待办同步

在思源「任务笔记管理」插件的待办任务与飞书「任务 (Task)」之间进行双向同步。

## 功能

- **双向同步**：支持创建、更新（标题/备注/截止时间）、完成与取消完成状态的同步。
- **同步方向可选**：双向、只从飞书到思源、只从思源到飞书。
- **定时 + 手动**：默认每 60 秒轮询，监听任务数据变化即时同步；顶栏和右侧停靠面板提供「立即同步」。
- **飞书清单多选**：可勾选多个清单；未选择时默认匹配「AI管家·每日待办」。
- **删除/移出标注**：
  - 一侧删除 → 另一侧标题追加 `-该任务同步后已删除`；
  - 一侧移出同步范围 → 另一侧标题追加 `-该任务同步后已转移到其他待办清单中`；
  - 移回同步范围后自动移除该标注。
- **冲突处理**：两边都修改时，按「最后修改时间优先」覆盖。
- **清空前备份**：清空并重同步前，可先备份到 WebDAV 或 OSS（S3 兼容，AWS Signature V4），备份失败会中止清空。
- **连通性测试**：飞书授权、WebDAV、OSS 写入测试。
- **脱敏 AI 诊断**：OpenAI 兼容接口，结合脱敏日志分析同步问题，提供对话式聊天框。
- **分区设置面板**：总览 / 飞书授权 / 任务清单 / 同步范围 / 备份 / AI 诊断 / 日志 / 危险操作。
- **历史日志**：持久化保存，可查看完整历史。
- **仅桌面端**：仅支持思源桌面客户端。

## 使用前提

需要「任务笔记管理」插件（`siyuan-plugin-task-note-management`）已安装并启用，且存在「飞书待办」分类（默认已内置 `category_feishu_todo`）。

## 飞书侧配置（一次性）

1. 登录[飞书开放平台](https://open.feishu.cn/)，创建「企业自建应用」，记录 **App ID** 与 **App Secret**。
2. 在「权限管理」中开通并申请任务相关权限，至少包含：
   - `task:task:read`
   - `task:task:write`
   - `task:tasklist:read`
   - `task:tasklist:write`
   - `offline_access`
3. 在「安全设置 > 重定向 URL」中添加 `http://127.0.0.1:18080/callback`。
4. 发布应用版本使权限生效。
5. 回到本插件设置，填入 App ID / App Secret，点击「授权飞书」完成授权。

## 设置项

- **飞书授权**：App ID / App Secret / Scope / OAuth 回调端口 / 授权状态 / 测试连接。
- **任务清单**：多选同步清单，未选时默认「AI管家·每日待办」。
- **同步范围**：同步方向、同步间隔、同步到飞书的分类、删除改为标题标注。
- **备份**：不备份 / WebDAV / OSS（S3），按需显示对应字段，并提供连通性测试。
- **AI 诊断**：API 地址、模型、Key，脱敏诊断与对话。
- **显示位置**：右侧栏 / 左侧栏 / 不显示停靠面板（顶栏始终保留）。

## 数据说明

- 读取任务插件存储：`data/storage/petal/siyuan-plugin-task-note-management/reminder.json`、`categories.json`。
- 飞书 → 思源写回 `reminder.json`（分类为「飞书待办」）。
